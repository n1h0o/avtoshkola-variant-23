# Автошкола - кабинет обучения

Учебный веб-прототип системы автошколы на Django 5.2 и SQLite. Реализованы роли курсанта, инструктора, преподавателя и администратора. Данные демонстрационные, персональные данные реальных пользователей не входят в репозиторий.

## Локальный запуск

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`.

## Демо-учётные записи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Курсант | `kursant` | `demo1234` |
| Инструктор | `instructor` | `demo1234` |
| Преподаватель | `teacher` | `demo1234` |
| Администратор | `admin_demo` | `demo1234` |

Команда `seed_demo` создаёт синтетические записи для демонстрации. Учётные данные не используйте на других сервисах.

## Функции

- Личный кабинет курсанта, профиль, прогресс и история практики.
- Поиск доступного времени и бронирование занятий.
- Рабочие кабинеты инструктора и преподавателя.
- Учёт теоретического зачёта и условия допуска к внутреннему экзамену.
- Адаптивная навигация, клиентские проверки и динамическая загрузка расписания через Fetch API.
- Пагинация расписания по 20 записей.

Особое правило варианта 23 проверяется сервером: автомобиль в брони должен соответствовать категории и коробке передач учебной программы. Для заявки на экзамен требуется зачёт теории и не менее 90% практики.

## Структура

- `config/` - настройки Django и корневые маршруты.
- `school/` - модели, формы, представления, маршруты, тесты и команда демонстрационных данных.
- `templates/school/` - HTML-шаблоны.
- `static/school/css/` - стили интерфейса.
- `static/school/js/` - мобильная навигация, клиентская проверка и динамическое расписание.

## Проверки

```powershell
python manage.py check
python manage.py test school -v 1
```

Это учебный проект для локального запуска. Перед публичным развёртыванием необходимо задать собственный `DJANGO_SECRET_KEY`, отключить режим отладки и настроить разрешённые домены. Файл `.env.example` содержит только названия переменных, секретных значений в репозитории нет.
